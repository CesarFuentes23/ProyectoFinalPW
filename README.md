# Orígenes SV
Sistema de gestión (ERP) y punto de venta para Orígenes SV, un restaurante y cafetería
con tres sucursales: Escalón, Santa Tecla y Santa Ana.
Proyecto final de Programación Web, Universidad Centroamericana "José Simeón Cañas",
ciclo 02-2026.
